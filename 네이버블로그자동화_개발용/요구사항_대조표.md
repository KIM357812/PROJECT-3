## 현재 완료를 막는 필수 항목

1. 같은 네이버 계정으로 로그인한 모바일 앱 또는 모바일 브라우저에서 프롤로그와 기술 글의 비공개 표시, 이미지 순서·잘림과 문단 간격을 육안 확인한다.
2. 사용자 Windows 바탕화면의 네이버 전용 실행 버튼을 실제 클릭해 전체 흐름의 시작·재개 상태를 확인한다. 자동화 세션에서는 프로세스 실행·자체 검사는 통과했으나 별도 WinForms 창이 화면 목록에 나타나지 않아 사용자 화면 확인이 남았다.

공개 게시, 로고·테마 공개 설정 변경과 Google Blogger 운영본 변경은 이 완료 조건에 포함하지 않는다.
