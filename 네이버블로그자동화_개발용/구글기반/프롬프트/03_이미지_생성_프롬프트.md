# ChatGPT 네이버 블로그 단일 이미지 생성 지시문

아래 입력자료 한 묶음만 사용하여 **가로형 단일 이미지 파일 한 장**을 생성한다.

## 절대 조건

- 결과 수는 정확히 1장이다.
- 하나의 캔버스에 하나의 연속된 장면만 표현한다.
- 콜라주, 2×2 그리드, 분할 화면, 멀티 패널, 연락처 시트, 이미지 모음을 만들지 않는다.
- 다른 번호 이미지의 장면이나 대상을 추가하거나 섞지 않는다.
- 입력자료의 상세 영문 프롬프트와 금지 요소를 모두 지킨다.
- 네이버 블로그 본문용 가로형 3:2 구도를 사용한다. 최종 게시용 사본은 1200×800px로 변환한다.
- 이미지 안에 제목, 설명문, 한글·영문 문장, 숫자, 임의의 글자와 홍보용 워터마크를 넣지 않는다.
- 기사의 핵심 기업·기관을 즉시 이해하는 데 필요하면 검증된 공식 로고 원본을 사용할 수 있다. 로고의 크기와 위치는 장면의 전달 목적에 맞게 정한다.
- AI에게 기업·기관 로고를 새로 그리게 하지 않는다. 로고가 필요하면 사실적 장면을 먼저 생성한 뒤 별도로 확보하고 검증한 공식 자산을 합성한다. 로고 글자·비율·색상·형태가 잘못되면 로고를 뺀 장면을 사용한다.
- 실제 산업 현장에서 가능한 장비 배치, 크기, 원근감과 조명을 사용한다.
- 문자가 없어도 주제를 알아볼 수 있도록 인물의 행동, 장비, 장소, 사건의 원인과 결과를 시각적으로 구체화한다. 추상 배경과 일반적인 기술 아이콘만으로 채우지 않는다.
- 과도한 공상과학 표현, 네온 효과, 홀로그램, 비현실적인 인터페이스를 피한다.
- 별도의 설명이나 프롬프트 요약보다 이미지 생성을 우선한다.

입력자료에 여러 항목이 적혀 있어도 모두 같은 한 장면을 구체화하기 위한 설명이다. 여러 장면으로 분할하지 않는다.

이 요청에서는 이미지 한 장만 생성하고 종료한다.

생성된 원본은 보존하고, 블로그에는 별도의 게시용 사본을 만들어 3:2·1200×800px·JPEG로 변환한 뒤 압축한다. 복잡한 장면도 450KB를 넘지 않도록 하며 용량 초과 시 화질을 단계적으로 조절한다.
