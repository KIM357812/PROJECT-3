# 네이버 블로그 안정 엔진 복원 검증

## 구현 결과

- 기사 수집·선택·사실검증·본문 생성은 제공된 Google 기반 사본의 안정 흐름을 우선 사용한다.
- 네이버 고유 이미지·편집기·모바일·링크·태그 기능은 유지한다.
- 여러 글은 사용자가 입력한 순서대로 한 건씩 완성하며, 첫 완성 글을 즉시 준비 목록에 표시한다.
- 실패 시 전체 수집이나 완성 글을 다시 만들지 않고 실패 단계만 자동 복구한다.
- 매체 목록은 설정 파일에서 이름·홈·피드·사이트맵·포함/제외 패턴을 바꿀 수 있다.

## 검증 결과

- 전체 자동·회귀 시험: 3회 연속 통과
- 보호 Google 기준 자료: 238개 파일의 경로·길이·SHA-256 변경 없음
- 실제 기사 생성: 제목·본문·이미지 4장·태그 5개·네이버 입력 패키지 생성 성공
- 증분 처리: 첫 완성 글의 패키지와 최종 결과 파일 생성 확인
- 발행 설정: 열지 않음

## 남은 사용자 조치

자동화 전용 Chrome 프로필에 네이버 로그인이 없어 실제 편집기 입력 사전검사가 `NAVER_LOGIN_REQUIRED`에서 안전하게 중단되었다. 로그인 후 동일 패키지로 편집기 입력과 발행 전 PC 화면 검증을 계속한다.
