# 네이버 새 글 자동화 수동 기사 선택 업그레이드 검증

검증일: 2026-11-08

## 적용 결과

- 지정 8개 매체에서 실행일 기준 최근 7일 이내 기사만 허용한다.
- 최근 20일·30일로 확대하는 규칙을 제거했다.
- AI·피지컬 AI, 데이터센터, 전력·에너지, 스마트그리드, 배터리, 온실가스, 지정 매체의 기타 최신 기술과 관련 우주기술을 후보 범위로 정했다.
- 후보 첫 항목 자동 선택을 제거했다.
- PowerShell에서 실제 후보 번호 1~3개를 입력하며 입력 순서를 보존한다.
- 이전 작성 URL은 후보에서 자동 제외하지 않는다. 현재 후보 목록의 동일 URL만 한 건으로 정규화한다.
- 선택한 글을 각각 독립 실행 패키지로 저장하고 작업 대기 자료를 만든다.
- 여러 글은 원하는 글부터 네이버 편집기에 한 건씩 입력할 수 있으며 완료 표식으로 중복 입력을 막는다.
- 사용자 화면의 `Google 완성 글` 입력 칸과 가져오기 버튼을 제거했다.
- 발행 설정 진입과 공개·비공개·예약 발행 기능은 추가하지 않았다.

## 자동 검증

- Windows PowerShell 5.1 전체 단위·정적·회귀 테스트 통과
- 최근 7일 경계 허용, 8일 이상 및 게시일 미확인 차단 통과
- 이전 작성 URL 선택 허용과 현재 후보 동일 URL 중복 제거 통과
- 사용자 선택 1~3개, 공백·쉼표, 중복 번호, 잘못된 번호, 입력 순서 보존 검사 통과
- 세 글 독립 패키지·실행패키지·작업 대기 자료 생성 검사 통과
- 사용자 화면 자체 검사와 화면 배치 검사 통과
- Google 참조 무결성 238개 파일 검사 통과

## 안전 조건

- Google 운영·개발 원본은 수정하지 않았다.
- 기존 네이버 운영 글을 수정하거나 삭제하지 않았다.
- 발행 설정을 열거나 게시하지 않았다.
- 실제 기사 선택과 새 네이버 편집기 입력은 사용자가 바탕화면 도구에서 후보 번호를 선택해 시작하는 운영 단계다.
