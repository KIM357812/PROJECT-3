# 공통 사실검증 자료 생성 프롬프트

선택된 기사와 독립적인 공식 자료를 대조해 매체 공통 사실검증 자료를 만든다. 네이버 글을 먼저 작성하지 않는다.

## 필수 항목

- 콘텐츠 고유번호
- 원문 제목, URL, 매체명, 게시일, 확인일
- 핵심 사실과 핵심 수치·단위
- 기업·기관·인물, 장소와 시점
- 발표·계획·투자·실증·상용화·실적 구분
- MW/MWh, GW/GWh, 퍼센트/퍼센트포인트, 목표/실적, 최대/평균/예상 구분
- 원문에서 확인한 내용과 작성자의 분석 구분
- 자료 간 불일치와 가능한 원인
- 기사 오류·과장 가능성과 정정 근거 URL
- 아직 확인되지 않은 부분과 후속 확인 항목

## 선정 기사 기반 육하원칙 자료

- 육하원칙은 블로그 본문을 작성하기 전에 선정된 원문 기사에서 먼저 추출한다. 완성된 블로그 본문이나 작성자의 해설을 다시 요약해 만들지 않는다.
- `articleFiveWOneH.provenance`는 `selectedArticle`, `sourceUrl`은 선택한 기사의 `primarySource.url`과 정확히 같아야 한다.
- `who·what·when·where·how·why`마다 `value`와 `evidence`를 기록한다. `value`는 네이버 육하원칙 상자에 그대로 사용할 간결한 개조식 문구이고, `evidence`는 원문에서 그 판단을 뒷받침하는 문장·문단의 핵심 근거다.
- `누가`는 기사를 쓴 매체 자체가 아니라 기사 속에서 발표·결정·실행·영향을 받은 실제 주체를 먼저 적는다. 매체명·기자명은 출처 정보로 별도 보존한다.
- `언제`는 기사 게시일과 기사 속 사건일을 구분한다. 사건일이 기사에서 확인되지 않으면 임의로 만들지 말고 `기사에서 구체적 사건일 확인되지 않음`으로 적는다.
- 기사에 없는 항목은 공식자료로 채워 육하원칙을 바꾸지 않는다. 해당 항목은 `선정 기사에서 확인되지 않음`으로 남기고, 공식자료의 보충·정정 내용은 별도의 교차검증 항목에 기록한다.
- 여섯 항목 중 하나라도 값·근거가 비어 있거나 출처 URL이 선정 기사와 다르면 네이버 초안 작성을 시작하지 않는다.

다음 구조로 저장한다.

```json
{
  "articleFiveWOneH": {
    "provenance": "selectedArticle",
    "sourceUrl": "선정 기사의 고유 상세 URL",
    "who": { "value": "간결한 개조식", "evidence": "기사에서 확인한 근거" },
    "what": { "value": "간결한 개조식", "evidence": "기사에서 확인한 근거" },
    "when": { "value": "간결한 개조식", "evidence": "기사에서 확인한 근거" },
    "where": { "value": "간결한 개조식", "evidence": "기사에서 확인한 근거" },
    "how": { "value": "간결한 개조식", "evidence": "기사에서 확인한 근거" },
    "why": { "value": "간결한 개조식", "evidence": "기사에서 확인한 근거" }
  }
}
```

확인할 수 없는 내용을 추측하지 않는다. 오류라고 단정할 때는 정부·규제기관·기업 공식 발표 등 신뢰 가능한 근거 URL을 제시한다. 근거가 충분하지 않으면 공개 자료 간 차이 또는 확인 불가로 표시한다.
