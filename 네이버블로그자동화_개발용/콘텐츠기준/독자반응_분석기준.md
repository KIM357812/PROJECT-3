# 네이버 독자 반응 분석 기준

## 목적과 우선순위

네이버 공식 작성·검색·스마트에디터 기준을 먼저 적용한다. 그 범위 안에서 실제 구독자 반응을 두 번째 기준으로 사용해 글 길이, 관심 주제, 검색어와 모바일 편집 방향을 보완한다. 분석 결과는 검색 노출이나 방문 증가를 보장하지 않는다.

## 확인된 네이버 통계 항목

2026-11-05 네이버 블로그 관리 화면을 읽기 전용으로 확인했다. 조회수, 순방문자수, 방문 횟수, 평균 방문 횟수, 재방문율, 평균 사용 시간, 유입 분석, 시간대, 성별·연령, 기기, 이웃, 국가 분포와 게시물별 조회수·공감수·댓글수 순위가 제공된다.

자동화에는 콘텐츠 개선에 필요한 집계값만 입력한다. 개인별 방문 기록, 사용자 식별자, IP 주소와 성별·연령·국가 데이터는 저장하지 않는다.

## 근거 충분 기준

- 관찰 기간 14일 이상
- 분석 대상 게시물 5개 이상
- 총 조회수 100회 이상
- 검색어 추천은 검색 유입 30회 이상

하나라도 충족하지 못하면 `insufficient`로 판정하고 글 길이는 기본 목표인 2,000~3,000자를 유지한다. 자동검사 허용 범위는 1,700~3,300자다. 현재처럼 게시물이 없는 상태에서는 독자 선호를 추정하지 않는다.

## 조정 방법

- 글 길이: 조회수 상위 40% 게시물의 본문 글자 수 중앙값에 ±20% 범위를 적용하되 1,700~3,300자를 벗어나지 않는다.
- 긴 주제: 3,300자를 넘길 내용은 반복·압축으로 맞추지 않고 독립적으로 이해되는 연재 글로 나눈다.
- 관심 주제: 같은 카테고리에 게시물이 2개 이상 있을 때만 게시물당 평균 조회수를 비교한다.
- 검색어: 검색 유입 표본이 30회 이상일 때만 상위 5개를 참고한다. 본문에 반복 삽입하지 않고 독자의 질문과 검색 의도를 파악하는 데만 쓴다.
- 모바일: 모바일 비율이 60% 이상이면 모바일 우선 신호로 표시한다. 기존 220자 이하 문단 기준은 계속 적용한다.

분석 입력과 결과는 운영 계정이나 소스 저장소에 자동 저장하지 않는다. 사용자가 선택한 저장소 밖 작업 폴더에 버전별 JSON으로 보관하고 기존 파일은 덮어쓰지 않는다.
