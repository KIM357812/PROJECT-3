# 네이버 스마트에디터 요소 식별 기준

확인일: 2026-11-05  
대상: `https://blog.naver.com/ij1128` 새 글 편집기

빈 새 글 편집기를 읽기 전용으로 관찰한 결과다. 글 입력, 임시저장과 발행은 실행하지 않았다.

## 기본 구조

- 편집기는 최상위 문서의 `iframe#mainFrame` 안에 있다.
- 제목 영역은 `article` 아래 `data-a11y-title="제목"` 속성을 가진 컴포넌트다.
- 본문 영역은 `article` 아래 `data-a11y-title="본문"` 속성을 가진 컴포넌트다.
- 제목과 본문의 실제 텍스트 노드는 각각 해당 컴포넌트 내부의 `.__se-node`에서 확인된다.
- `SE-...` 형식의 `id`는 새 편집기마다 달라지므로 자동화 선택자로 사용하지 않는다.
- `input_buffer...` 형식의 iframe 번호도 실행마다 달라지므로 고정 선택자로 사용하지 않는다.

## 역할·이름 기반 요소

- 상단 임시저장 후보: 역할 `button`, 이름 `저장`
- 임시저장 목록: 역할 `button`, 이름이 `임시저장된 글 보기`로 시작
- 발행 설정 열기: 역할 `button`, 이름 `발행`
- 발행 설정 닫기: 역할 `button`, 이름 `발행 설정 닫기`
- 카테고리: 역할 `button`, 이름 `카테고리 목록 버튼`
- 공개 범위: 역할 `radio`, 이름 `전체공개`, `이웃공개`, `서로이웃공개`, `비공개`
- 태그: 역할 `combobox`, 이름 `태그 입력 (최대 30개)`
- 발행 시간: 역할 `radio`, 이름 `현재`, `예약`
- 공지 등록: 역할 `checkbox`, 이름 `공지사항으로 등록`
- 게시 직전 최종 버튼: 발행 설정 패널 내부의 역할 `button`, 이름 `발행`

관찰 당시 카테고리 버튼에는 `AI·데이터센터`가 표시됐고, 새 글 기본 공개 범위는 `전체공개`였다. 자동화는 기본값을 신뢰하지 않고 비공개 여부를 매 실행마다 다시 확인해야 한다.

## 사용하지 않을 선택자

- `save_btn__...`, `publish_btn__...` 등 빌드마다 바뀔 수 있는 해시형 CSS 클래스
- `SE-...` 동적 ID
- 화면 좌표만 사용하는 클릭
- 버튼 순서만 가정하는 `nth()` 선택
- 임시 입력 버퍼 iframe의 숫자 ID

## 안전한 입력·저장 순서

1. `iframe#mainFrame`이 보이는지 확인한다.
2. 제목·본문 컴포넌트가 각각 한 개만 존재하는지 확인한다.
3. 제목과 본문을 입력한 뒤 화면에서 실제 문자열을 다시 읽어 비교한다.
4. 발행 설정을 열고 카테고리·태그·공개 범위를 확인한다.
5. 테스트 글은 `비공개`를 명시적으로 선택한다.
6. 최종 `발행` 버튼은 공개·비공개와 관계없이 외부 저장 동작이므로 실행 직전에 사용자 승인을 받는다.
7. 상단 `저장` 버튼이 실제 임시저장 동작인지 별도 승인된 테스트로 확인하기 전에는 자동 클릭하지 않는다.

## 이미지 글 저장 지연 복구

- 기술 글은 저장 전에 이미지 3장의 파일명·순서·삽입 위치를 다시 읽는다.
- 각 이미지 주소가 `blogfiles.pstatic.net` 또는 `postfiles.pstatic.net`으로 바뀌었는지 확인해 네이버 서버 업로드 완료 여부를 판정한다.
- `발행 중입니다. 잠시만 기다려주세요.`가 60초를 넘으면 같은 버튼을 반복 클릭하거나 즉시 새로고침하지 않는다.
- 멈춘 탭은 그대로 유지하고, 게시물 화면의 공식 `수정` 링크로 새 편집창을 한 번만 연다.
- 새 편집창에서 제목·본문·이미지 3장·카테고리·태그·비공개를 다시 확인한 뒤 비공개 저장을 한 번만 재시도한다.
- 성공 판정은 게시물 화면 이동, `비공개` 표시, 이미지 3개의 네이버 서버 주소와 올바른 순서를 모두 확인했을 때만 한다.
- 첫 시도 지연 여부, 총 저장 시도 횟수와 복구 동작을 관찰 결과에 기록한다. 두 번째 시도도 실패하면 자동 재시도를 중단하고 원인을 보고한다.

## 다음 검증

- 승인된 테스트 원고로 제목·본문 입력 후 실제 텍스트 재확인
- 카테고리 선택과 태그 5~10개 입력
- `비공개` 선택 후 상태 재확인
- 상단 `저장` 버튼과 임시저장 목록 증가 여부 확인
- PC 화면과 모바일 미리보기의 문단·링크·태그 확인
