# 글별 부분 성공·실패 재시도 검증 보고서

- 검증일: 2026-11-09
- 브랜치: codex/naver-blog-semi-automation
- 범위: 글별 독립 처리, 부분 성공 반환, 실패 글 전용 재시도, 네이버 결정 서식 자동 보정, Windows 화면 분리

## 확인 결과

- 3개 중 생성 성공·생성 실패·네이버 패키지 실패를 각각 분리해 보존함
- 완성 글은 다른 글의 실패와 무관하게 작업 대기 목록에 제공함
- 실패 글 재시도에서 기사 검색과 번호 선택을 다시 실행하지 않음
- 재시도 시 기존 완성 패키지를 중복 생성하지 않음
- 정확한 작업 상태 경로를 재시도 실행기에 전달함
- 반응형 데이터 표 data-label과 확정 서식을 코드로 자동 교정 후 재검증함
- Windows 화면에서 새 작업, 실패 재시도, 완성 패키지 입력 재개를 서로 다른 버튼으로 제공함
- 전체 자동 테스트 통과
- Google 참조 원본 238개 경로·길이·SHA-256 무변경 확인
- 네이버 발행 설정 미진입, 공개·비공개 발행 미실행

## 2차 재검토 보완

- 성공한 재시도 뒤 과거 실패 작업이 다시 재시도 대상으로 나타날 수 있던 상태 선택 문제를 수정했다.
- 같은 작업의 작업대기 이력 중 가장 최신 결과만 유효하게 판정하고, 해결된 과거 실패 이력은 다시 선택하지 않는다.
- 재시도 상태 경로가 현재 작업 폴더의 작업대기 영역 안에 있는지 확인해 외부 상태 파일을 차단한다.
- 같은 초 단위에 재시도해도 패키지 ID와 작업대기 파일명이 충돌하지 않도록 밀리초와 고유 식별자를 추가했다.
- 이전 작업대기 결과를 덮어쓰지 않는지와 해결된 실패를 다시 재시도하지 않는지를 회귀 시험으로 추가했다.
