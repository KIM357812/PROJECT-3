# 편집기 실행 모듈

`프로그램/편집기실행기.mjs`는 Chrome 탭의 승인된 브라우저 제어 API를 받는 실행 모듈이다. PowerShell 단독 브라우저 드라이버가 아니며 로그인 세션을 추출하지 않는다.

`편집기현재글서식복구계획.ps1` 결과의 `executor.modulePath`에서 모듈을 불러온 뒤 `createEditorRunner(domTab, nativeTab).run(plan)`을 호출한다. 동일 모듈의 `apply`, `space`, `audit`로 단계를 나누어 실행할 수도 있다. `audit`는 마지막에 전체 대상을 다시 읽는다.

현재 구현 범위는 소제목과 육하원칙 서식 복구다. 문단을 식별한 뒤 네이버 자체 메뉴와 네이티브 입력으로 적용한다. DOM은 읽기와 측정에만 사용한다. 공개·비공개 발행 버튼은 호출하지 않는다.

- 네이버 소제목 문단 스타일의 30px를 피하기 위해 본문 문단에 크기·굵기를 명시한다. 큰 소제목 19px, 작은 소제목은 편집기에서 지원하는 16px로 적용한다.
- 제목 앞 간격 문단 32px, 뒤 21px. 연속 제목 사이는 앞 제목의 뒤 여백과 다음 제목의 앞 여백을 더하지 않고 32px 하나를 공유한다.
- 육하원칙의 원본 leaf div도 파싱한다. 설명은 일반 굵기, 항목명만 굵게 처리한다.
- `TypographyVerified`는 글꼴 검증 결과일 뿐 전체 완료가 아니다. `audit.passed`도 위 범위만 검증하며 이미지·출처·모바일·전체 자동화 완료를 의미하지 않는다.

검증: `node --test 네이버블로그자동화_개발용/테스트/편집기실행기.test.mjs` 및 PowerShell `편집기현재글서식복구계획_테스트.ps1`.
