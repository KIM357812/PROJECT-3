# 실패 단계 자동복구 검증 보고서

## 적용 결과

- 사용자 화면과 실행 분기에서 수동 실패 재시도 기능을 제거했다.
- 선택 글은 최대 2건씩 병렬 처리하며, 각 글은 독립 상태 파일을 사용한다.
- 글 생성과 네이버 패키지 변환은 실패 단계에서 최대 3회 내부 자동복구한다.
- 완료 글과 실행 패키지는 보존하고 기사 수집·번호 선택을 반복하지 않는다.
- 중단된 `글 작성 중` 상태가 있으면 저장된 선택 번호와 완료 목록을 사용해 자동 재개한다.
- 사용자 화면에는 준비 중, 전체 완료 또는 실제 자동복구 불가 원인만 한 번 표시한다.

## 상태 기록

글별 상태에는 선택 번호, 원문 URL, 현재 단계, 통과 단계, 오류 코드, 자동복구 횟수, 마지막 검증 결과와 완료 패키지 경로를 기록한다. 네이버 패키지 단계는 5단계부터 시작해 편집기 입력 패키지가 완성되면 9단계 완료로 기록한다.

## 보호 및 검증

- Google Blogger 운영 원본은 수정하지 않는다.
- 보호 기준 SHA-256 검증을 전체 시험의 시작과 끝에서 실행한다.
- 수동 재시도 용어·버튼·이벤트·명령이 활성 코드에 남지 않았는지 전용 시험으로 검사한다.
- 전체 회귀시험은 동일 코드로 3회 연속 실행해 모두 통과해야 한다.
