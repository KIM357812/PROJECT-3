# 관련 글 선정 기능 검증 보고서 (2026-11-09)

## 적용 결과

- 기존 네이버 관련 글 화면 디자인과 HTML 형식은 변경하지 않았다.
- 동일 네이버 블로그의 공개 글 가운데 현재 글보다 먼저 공개된 최근 60일 글만 후보로 사용한다.
- 제목·태그·본문 일치도를 먼저 계산하고, 반복 사용 링크에는 감점을 적용한다.
- 관련 글은 최대 3개이며 후보가 부족하면 1~2개만 표시하고, 후보가 없거나 목록 조회에 실패하면 영역 전체를 생략한다.
- 같은 세 링크 조합은 충분히 관련된 대체 후보가 있을 때만 교체한다.
- 실제 공개 주소를 정규화하며 현재 글, 미래 글, 다른 블로그 글, 중복 URL·제목은 제외한다.

## 자동 검증

- 관련 글 전용 회귀 테스트: 통과
- 전체 네이버 자동화 테스트: 통과
- 관련성 우선, 60일 제한, 미래 글·현재 글·타 블로그 제외, 최대 3개, 후보 부족·없음 처리, 반복 감점, 조합 대체, URL 비노출 검증: 통과
- Google 참조 무결성: 238개 파일 경로·길이·SHA-256 불변
- 실제 네이버 공개 목록 조회: 현재 공개 글 0건으로 정상 응답, 관련 글 영역 생략 동작 확인

## 작업 경계

- 기존 네이버 운영 글은 수정·삭제하지 않았다.
- 네이버 편집기 입력, 발행 설정 열기, 공개·비공개 발행은 실행하지 않았다.
- Google Blogger 자동화 파일은 수정하지 않았다.
