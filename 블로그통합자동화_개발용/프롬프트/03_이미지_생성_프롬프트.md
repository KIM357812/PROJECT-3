# Gemini 단일 블로그 이미지 생성 지시문

아래 입력자료 한 묶음만 사용하여 **가로형 단일 이미지 파일 한 장**을 생성한다.

## 절대 조건

- 결과 수는 정확히 1장이다.
- 하나의 캔버스에 하나의 연속된 장면만 표현한다.
- 콜라주, 2×2 그리드, 분할 화면, 멀티 패널, 연락처 시트, 이미지 모음을 만들지 않는다.
- 다른 번호 이미지의 장면이나 대상을 추가하거나 섞지 않는다.
- 입력자료의 상세 영문 프롬프트와 금지 요소를 모두 지킨다.
- 블로그 본문용 가로형 16:9 구도를 사용한다.
- 이미지 안에 제목, 설명문, 문자, 숫자, 제3자 로고나 홍보용 워터마크를 넣지 않는다. Gemini가 서비스 차원에서 자동 부여하는 제공자 표시 또는 SynthID는 허용하며 실패 사유로 보지 않는다.
- 실제 산업 현장에서 가능한 장비 배치, 크기, 원근감과 조명을 사용한다.
- 과도한 공상과학 표현, 네온 효과, 홀로그램, 비현실적인 인터페이스를 피한다.
- 별도의 설명이나 프롬프트 요약보다 이미지 생성을 우선한다.

입력자료에 여러 항목이 적혀 있어도 모두 같은 한 장면을 구체화하기 위한 설명이다. 여러 장면으로 분할하지 않는다.

이 요청에서는 이미지 한 장만 생성하고 종료한다.
