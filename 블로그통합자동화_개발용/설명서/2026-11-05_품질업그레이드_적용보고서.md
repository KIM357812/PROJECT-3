# 블로그 통합 자동화 품질 업그레이드 적용 보고서

적용일: 2026-11-05

## 적용한 기준

- 새 글의 화면 표시 분량은 원칙 1,300~4,800자이며, 반복 없이 핵심이 완결되는 글만 1,000~1,299자 예외를 허용한다. 예외 사유는 내부 사실검증표에 남긴다.
- 기사 정보에 맞춰 H2 3~4개, 결론 H3 2~3개를 사용한다. 육하원칙 박스는 유지하고, 추가 핵심 정보 박스는 필요할 때 한 개만 허용한다.
- AI·피지컬 AI·IT·전력·에너지·데이터센터·스마트그리드·신재생에너지·온실가스 감축을 중심으로 최신성과 구독자 관심도를 함께 본다. 우주 분야는 이 주제들과 연결되는 기사를 우선한다.
- 제목은 최종 권장 제목 1개와 대체 제목 2개를 만든다. 사실에 맞는 후킹성은 허용하되 낚시성·과장·본문에 없는 약속은 금지한다.
- 공개 출처는 질문 상자 아래 한 줄에 매체명 링크 1~3개만 표시한다. 본문 링크는 핵심 수치·발표일·정책·공식 발표·오류 정정·중요 주장으로 제한하고 보이는 문구는 공백 포함 15자 미만으로 제한한다.
- 출처는 핵심 요약과 같은 회색 배경에서 왼쪽 세로선 없이 제목·링크를 한 문단으로 가로 배치하고, 관련 글은 목차와 같은 연한 파란색 배경을 사용하며 두 영역의 제목과 링크는 14px로 통일한다.
- 공개 블로그 피드에서 기존 글을 확인한다. 같은 사건은 새 사실이나 새로운 분석이 있을 때만 후속 글로 작성하며, 실제 관련 글만 0~3개 연결한다.
- 내부 숨김 `사실검증표.md`에 핵심 주장, 구분, 확인 URL, 확인일, 검증 결과와 정정 내용을 3건 이상 기록한다.
- 일반 본문은 오른쪽 끝이 가지런한 양쪽 정렬과 마지막 줄 왼쪽 정렬을 사용하고, 긴 영문 용어가 모바일 화면을 넘지 않도록 줄바꿈 속성을 적용한다.
- 이미지 4장은 유지한다. 첫 이미지는 우선 로딩하고 나머지는 지연 로딩하며, 설명형 WebP 파일명을 사용한다. Gemini 제공자 표시·SynthID는 허용하지만 제3자 로고, 홍보용 워터마크, 깨진 글자와 잘못된 장면은 허용하지 않는다.
- 본문 최대 폭 800px, 이미지 최대 폭 400px·가운데 정렬·모바일 자동 축소와 `Blogger에_붙여넣을_본문.html` 중심 작업 방식은 유지한다.
- 네 이미지 부모 영역은 위·아래를 각각 28px로 고정해 이미지 다음 문단이나 소제목이 붙지 않게 한다.
- 모바일 데이터 표는 좁은 다열 표를 그대로 축소하지 않고, 각 셀에 열 제목을 함께 표시하는 `항목명–값` 카드형으로 바꾼다.
- 내부 `본문.html`은 사용자 글 폴더에 만들지 않고 별도 백업 위치에만 저장하여 게시용 HTML과 혼동되지 않게 한다.

## 프로그램이 자동으로 차단하는 항목

- 분량, H2·H3 개수, 육하원칙 여섯 항목, 이미지 정확히 4개
- 일반 본문과 육하원칙 내용의 양쪽 정렬·마지막 줄 왼쪽 정렬, 데이터 표의 휴대전화 세로형 카드 변환
- 첫 이미지의 우선 로딩과 나머지 이미지의 지연 로딩
- 본문 최대 800px, 이미지 최대 400px·가운데 정렬·모바일 대응
- 이미지 부모 영역 4개의 위·아래 28px 간격
- 내부 사실검증 항목 3개 미만이면 공개 본문과 메타데이터를 유지한 채 사실검증표만 한 번 자동 보완하고 다시 검사
- 일반 문단의 양쪽 정렬·마지막 줄 왼쪽 정렬과 긴 영문 줄바꿈
- 공개 출처 1~3개, 선택 기사 URL 포함, 본문 링크와 출처 URL 일치
- 공개 기존 글 목록에 없는 관련 글 링크
- 최종 제목 1개·대체 제목 2개의 존재와 중복, 최종 제목과 본문 핵심어의 최소 일치
- 이미지 프롬프트 여섯 필드, 설명형 WebP 파일명, 이미지별 필수 품질 문구
- 내부 사실검증 항목 3건 이상과 필수 여섯 필드, 선택 기사 URL 검증 기록
- 1,000~1,299자 글의 구체적인 예외 사유

의미 판단이 필요한 사실 정확성, 제목의 실제 매력도, 이미지가 글 이해에 기여하는 정도는 프롬프트의 자체 검토와 게시 전 사용자 확인을 함께 사용한다.

## 이번 작업에서 변경하지 않은 범위

- 기존 게시글은 수정하지 않는다.
- 사용자가 직접 수정한 운영자 소개의 이름과 총 경력은 변경하지 않는다.
- 새 글 본문에는 경력 연수를 반복하지 않고, 필요한 경우 `관련 업무 경험에 비추어 보면`처럼 업무 전반을 포괄하는 표현을 사용한다.
- Blogger 이미지 업로드·공개 게시, Search Console·AdSense 연동, 휴대전화 승인과 Gemini API 이미지 자동 생성은 이번 범위에 포함하지 않는다.
