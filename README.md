# 블로그통합자동화 개발용

현재 업무에 사용 중인 바탕화면 프로그램을 보호하기 위한 별도 개발 저장소입니다.

## 확정된 소재 기준

- 대상 매체: 8개 사이트
- 사이트별 최대 2개
- 전체 최대 16개
- 작성 완료 URL과 같은 실행 안의 중복 URL은 제외

## 보호 원칙

- 바탕화면 운영본은 이 저장소에서 수정하지 않습니다.
- 모든 코드는 `블로그통합자동화_개발용` 안에서만 수정합니다.
- 운영 글, 원본 이미지, 압축 이미지, 브라우저 세션, 인증정보는 GitHub에 올리지 않습니다.
- Codex Cloud의 변경은 로컬 Windows 개발용 복사본에서 다시 검증합니다.
- 실제 게시와 운영본 교체는 사용자 승인 후에만 수행합니다.

## 1차 업그레이드 범위

1. 이미지 변환 임시파일 자동 정리
2. 실행 전 환경 점검
3. 모델과 운영값 설정 파일 분리
4. 작업 상태 기록과 실패 글 재시도
5. 글·원본 이미지 자동 백업
6. 직원용 버튼 실행 화면
7. PowerShell 자동 검증 보강
8. 질문 상자 아래 클릭 가능한 출처 1~3개와 제한적 본문 링크 검증
9. 소제목별 핵심구절 강조 및 허용 분야만 경험 표현
10. 이미지 4장 자동 WebP 변환·백업·로컬 미리보기
